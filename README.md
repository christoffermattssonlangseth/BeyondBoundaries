# Beyond Boundaries

Extracting per-cell biological information from Xenium Multimodal Cell Segmentation stains
(DAPI, ATP1A1/CD45/E-Cadherin, 18S, αSMA/Vimentin) in mouse EAE spinal cord (RRMAP2, runs 5/6).

- `scripts/00_inspection/` — bundle/annotation inspection (step 0)
- `RESULTS.md` — running log of what was run, key numbers, open questions
- `results/` — figures + tables per phase
